# Protótipo navegável

Abra `index.html` diretamente em um navegador moderno. Não há dependências externas.

Telas disponíveis pela navegação lateral: Visão geral, Prospecção, Empresas, Leads, Pipeline, Assistente IA, Propostas, Relatórios, Assinatura e Configurações.

O protótipo tem alguns comportamentos locais (navegação, seleção de resultados e envio de mensagem demonstrativa). Não possui backend, autenticação, banco, OpenAI ou Asaas conectados. Todos os nomes, indicadores, preços, empresas e mensagens são fictícios e servem somente para referência visual.
